# yeplanu

Світлий вебзастосунок, щоб знайти компанію на вечір у Києві та області: пиво, ігри, кіно, прогулянка, шашлики або просто посидіти.

## Запуск

```bash
npm install
npm run dev
```

Відкрий [http://localhost:5173/](http://localhost:5173/).

## Що вміє

- Стрічка «Хто сьогодні хоче потусити?»
- Радіус 1 / 5 / 10 / 30 км
- Групові збори з лімітом місць
- Карта з реальною геолокацією (лише Київ і область)
- Запросити / Цікаво, рейтинг після зустрічі
- Верифікація телефоном і фото (у тесті код `1234`)

Стек: Vite, React, TypeScript, Tailwind, Leaflet. API крутиться разом із dev-сервером.
